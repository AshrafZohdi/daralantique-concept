How buying works

  1. 1

    Find it on the shelves

    Every piece has photos, its condition and an item code. Filter by shelf, or by whether it is still sealed.

  2. 2

    Message us the code

    Tap Ask on WhatsApp on any item. The message arrives with the code filled in, so we know exactly which one you mean.

  3. 3

    Pick it up in Al Khor

    We hold it for you at the shop. Ask us about delivery inside Qatar if you cannot make it.
